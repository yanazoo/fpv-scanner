# 5.8GHz FPV スキャナー（XIAO ESP32-C5 + XIAO ESP32-S3）

XIAO ESP32-C5 を ESP-SDR の受信専用機として使い、XIAO ESP32-S3 が 2.4GHz の
Wi-Fi アクセスポイントと Web サーバーになって、スマホのブラウザに 5GHz 帯の
スペクトラムを表示します。

C5 側のファームウェアは [ESP-SDR](https://github.com/ESPARGOS/esp-sdr)（ESPARGOS）の
本家版をそのまま使います。このリポジトリは S3 側のプログラムです。

```
[XIAO ESP32-C5]  --UART 2Mbaud-->  [XIAO ESP32-S3]  ~~2.4GHz Wi-Fi~~>  スマホのブラウザ
 ESP-SDR 本家ファーム               このプロジェクト（PlatformIO）
 5GHz を受信・FFT                   周波数スイープ・合成・Web表示
```

C5 は 1 回に約 30MHz 幅（40MS/s 設定時）しか見られないため、S3 が C5 の周波数を
順に切り替えて（既定の 5650〜5850MHz なら 7 ステップ）スペクトラムをつなぎ合わせます。

### スキャン範囲（スパン）とステップ

| ステップ幅（画面の選択） | C5 のサンプルレート | アナログフィルタ | 既定 200MHz のステップ数 | FFT 1 ビンの幅 |
| --- | --- | --- | --- | --- |
| 40 MHz（既定） | 80 MS/s | 44 MHz | 5 | 78 kHz |
| 30 MHz | 80 MS/s | 32 MHz | 7 | 78 kHz |
| 15 MHz | 40 MS/s | 16 MHz | 14 | 39 kHz |
| 7.5 MHz | 20 MS/s | 11 MHz | 27 | 20 kHz |

各ステップでは LO の周りのステップ幅ぶんだけを使い、サンプルレートをその 2 倍以上、
アナログフィルタをステップ幅程度にしています。ステップの外にある強い電波が
折り返して（エイリアス）別の周波数に映り込むのを防ぐためです。

FFT は 1024 ビンです。画面は 1 スパン 1000 点なので、これより細かいビンは表示に
現れず、C5 の計算と UART 転送が半分で済みます。

画面は 5 秒間データが届かないと自動で WebSocket を張り直します（スマホのスリープ
復帰時など）。S3 側も応答のない接続を切断します。

### 5GHz 帯のスペクトラムの向き

C5 の 5GHz 帯のスペクトラムは、受信の中心周波数（LO）を軸に左右反転して届きます
（実測: R2〜R5 の VTX が、すべてのステップで LO を挟んだ反対側に表示された）。
S3 は 4000MHz 以上の LO ではスペクトラムを反転して並べます。

受信設定の初期値: ステップ幅 40MHz、滞在 25ms、検波 最大値、ゲイン 10、
dBm 補正値 0.0dB。
強い電波の映り込みを減らしたいときは、ステップ幅 30MHz（フィルタ 32MHz）を選んでください。

- スパンは開始・終了とも 2300〜6000MHz の範囲で、5MHz 以上の幅を指定できます。
- 画面に送る点数は常に 1000 点です（200MHz なら 1 点 0.2MHz、各点はその中の最大値）。
- 1 スイープの時間はおおよそ「ステップ数 ×（周波数切替・校正 + 滞在時間）」です。
  ステップ数を減らす（スパンを狭める・レートを上げる）と更新が速くなります。
- 画面上部の「適用中」の行に、実際にスイープしている設定（範囲、レート、ステップ数、
  滞在時間、検波、ゲイン、補正値、1 スイープの時間）を表示します。「適用」を押すと
  現在のスイープを中断してすぐ新しい設定で測り直し、反映されるまで「変更を反映中…」と
  表示します。範囲外のゲインは C5 に拒否され、自動に戻してエラーを表示します。

## 1. 配線

| XIAO ESP32-C5 | XIAO ESP32-S3 |
| --- | --- |
| D6 (GPIO11, TX) | D7 (GPIO44, RX) |
| D7 (GPIO12, RX) | D6 (GPIO43, TX) |
| GND | GND |
| 5V（または 3V3） | 5V（または 3V3） |

TX と RX はたすき掛けです。C5 は無線起動時に電流が増えるので、電源は USB など
余裕のあるものから取ってください。C5 には 5GHz 対応のアンテナを付けてください。

## 2. XIAO ESP32-C5 の書き込み（1 回だけ）

本家のブラウザインストーラーで ESP-SDR を書き込みます。改造は不要です。

1. PC の Chrome / Edge で <https://espargos.net/espsdr/app/flash.html> を開く
2. C5 を USB 接続し、**ESP32-C5** のファームウェアを選んで書き込む

書き込み後、C5 は USB と UART（D6/D7, 2Mbaud）の両方でコマンドを受け付けます。

## 3. XIAO ESP32-S3 の書き込み（PlatformIO）

1. Visual Studio Code に PlatformIO 拡張を入れる
2. このリポジトリを clone（または ZIP でダウンロード）し、そのフォルダを「フォルダーを開く」で開く
3. Wi-Fi の初期値は SSID `FPV-Scanner`、パスワード `fpv-sa00` です（公開済みの値）。
   変更する場合は `src/config.h` の `AP_SSID` / `AP_PASSWORD` を書き換えます
   （パスワードは 8 文字以上）
4. S3 を USB 接続し、PlatformIO の「Upload」（→ボタン）で書き込む

書き込みで `No serial data received` などのエラーが出るとき:

- **C5 との配線（D6/D7）を外すか、C5 の電源を切ってから書き込む。**
  S3 の D6/D7 は書き込み用の UART0 と同じピンで、C5 からのデータが書き込みを妨げます
- それでも失敗する場合は、S3 の BOOT ボタンを押したまま RESET ボタンを押して離し、
  BOOT を離してから Upload する（書き込み後は RESET を押す）
- USB ハブを使わず PC に直接つなぎ、データ通信対応のケーブルを使う

## 4. 使い方

1. 両方のボードに電源を入れる
2. スマホで Wi-Fi `FPV-Scanner` にパスワード `fpv-sa00` で接続する
3. キャプティブポータルで画面が自動的に開きます
   - iPhone: 接続するとログイン画面としてそのまま開きます
   - Android: 「ネットワークにログイン」の通知をタップします。
     「インターネットに接続されていません」と出たら「このまま接続」を選んでください
   - 開かない場合はブラウザで <http://192.168.4.1/> を開きます（どの URL を開いても
     この画面に転送されます）

画面の構成（上から）:

- **スペクトラム**: 横軸 MHz、縦軸 dBm。チェックしたバンドの FPV チャネルを縦線で表示。
  保存したノイズレベルを灰色の線で重ねて表示します
- **マーカー 4 個 (M1〜M4)**: ボタンでアクティブマーカーを選び、グラフかすぐ下の
  チャネル表をタップして配置。受信レベル (dBm)・最寄りの FPV チャネル・周波数を表示。
  「ピーク」で最大点に移動。「保存」でマーカー位置を保存し、次回起動時も同じ位置に
  なります。数値で表示するのはマーカーのレベルだけです
- **FPV チャネル表**: Band A/B/E/F/R × CH1〜8 の周波数。タップしたセルの周波数に
  アクティブマーカーを置きます（マーカーのあるセルは枠と淡い色付き）。アクティブマーカーが
  あるセルをもう一度タップすると、マーカーの選択だけを外します（マーカーはその周波数のまま
  計測を続けます。M1〜M4 ボタンの再タップでも同じ）。グラフに表示する
  バンドを選んで「適用」
- **スパン**: 開始/終了を指定し「適用」。プリセットは入力欄に入るだけなので、
  確認して「適用」を押します
- **受信設定**: ステップ幅、滞在時間、検波（最大値/平均）、ゲイン
  （-1 = 自動 AGC、2〜上限 = 固定）、dBm 補正値。「適用」で反映
- **ノイズレベル**: 「今のノイズを保存」で、直近の平均トレースをその場所のノイズとして
  保存します。VTX を止めてしばらく表示させてから押してください。ゲイン・ステップ幅・
  検波を変えると条件が合わなくなるため、保存したノイズは自動で消去されます
- **表示**（スペクトラム図の上）: ピークホールド（「リセット」で消去）、平均、縦軸の上限と範囲。
  入力した時点で反映され、自動で保存されます

「適用」「保存」を押した設定（スパン、受信設定、補正値、バンド表示、マーカー位置）と
表示設定と保存したノイズは S3 本体に保存され、次に電源を入れたときもその設定で
起動します。
変更して未適用のときは「適用」ボタンが黄色の枠になります。

### dBm 補正値の合わせ方

表示は「C5 の ADC 基準のレベル (dBFS) + 補正値」です。

1. ゲインを固定する（例: 40）。自動 (AGC) では基準が変わり dBm がずれます
2. 出力のわかっている送信機（例: 25mW = 14dBm の VTX）を、わかっている距離・
   アンテナで受ける。または信号発生器を使う
3. マーカーをその周波数に置き、表示が期待する dBm になるよう補正値を変えて「適用」

精度は目安です。ゲインやステップ幅を変えたら補正値も合わせ直してください。

## 5. タッチ液晶版（Waveshare ESP32-C5-Touch-LCD-2.8）

XIAO ESP32-S3 の代わりに Waveshare ESP32-C5-Touch-LCD-2.8（2.8 インチ 240×320
静電容量式タッチ液晶）を使うと、電源を入れるだけで本体の画面にスペクトラムと
マーカーのレベルが表示されます。スマホの Web 画面もこれまでどおり同時に使えます。

```
[XIAO ESP32-C5]  --UART 2Mbaud-->  [ESP32-C5-Touch-LCD-2.8]  ~~2.4GHz Wi-Fi~~>  スマホ
 ESP-SDR 本家ファーム               液晶表示 + Web 表示（このプロジェクト）
```

### 配線（液晶ボード裏の J8 ヘッダー）

| XIAO ESP32-C5 | 液晶ボード J8 |
| --- | --- |
| D6 (GPIO11, TX) | 8 番ピン GPIO3（RX） |
| D7 (GPIO12, RX) | 7 番ピン GPIO2（TX） |
| GND | 1 番または 5 番ピン GND |
| 5V | 2 番ピン USB_5V（液晶ボードを USB 給電するとき。電池で使う場合は次の「電源」を参照） |

ピンは `src/config.h` の `FPV_LCD` 側で変更できます。GPIO2 は起動時の設定ピンを兼ねる
ため、書き込みがうまくいかないときは XIAO C5 との配線を外してから書き込んでください。

### 電源（USB 給電とバッテリー駆動）

**USB 給電**: J8 の 2 番ピン（USB_5V）は液晶ボードの USB-C の 5V にそのままつながって
います。液晶ボードの USB-C に USB 充電器やモバイルバッテリーをつないでいるときだけ 5V
が出るので、上の表のとおり XIAO C5 の 5V ピンへつなげば両方が動きます。

**バッテリー駆動**: 液晶ボードを電池だけで動かすと USB_5V は 0V です（プログラムでは
出せません）。また XIAO C5 は液晶ボードの 3V3（J8 6 番）からでは起動しません。そこで
液晶ボードの電池を XIAO C5 の電池パッド（裏面の BAT+ / BAT-）にも分け、ロードスイッチ
（WeAct MT9700 ミニロードスイッチモジュール）を通して液晶ボードの電源ボタンと連動させます。
J8 の 3V3 は液晶ボードの電源が入っているときだけ出るので、これをスイッチの EN に使います。

```
液晶ボードの電池＋ ─────────── MT9700 モジュール VIN
                              MT9700 モジュール VOUT ── XIAO C5 の BAT+
J8 6 番（3V3） ── 10kΩ ──────── MT9700 モジュール EN
液晶ボードの電池− ──┬───────── MT9700 モジュール GND
                    ├───────── XIAO C5 の BAT−（GND）
                    └───────── J8 1 番（GND）

通信線はそのまま: XIAO D6 → J8 8 番、XIAO D7 → J8 7 番
J8 2 番（USB_5V）→ XIAO 5V の線は外す
```

- 液晶の電源オン → J8 に 3.3V → MT9700 がオン → XIAO C5 が電池で起動。
  液晶の電源オフ → XIAO C5 の電源も切れる
- MT9700 の入力範囲は 2.4〜5.5V なので、リチウム電池（3.0〜4.2V）で使えます。
  EN の上限は「VIN＋0.3V」のため、電池が減ったときに備えて 10kΩ を直列に入れています
- 取り付け前にモジュールで確認すること:
  - 端子名（VIN / VOUT / EN / GND）の位置
  - EN が High でオンになること（型番末尾の「-N」が Low でオンの意味なら動きが逆になる）
  - 電流制限が 0.5A 以上あること
- 確認: 液晶オフのとき MT9700 の VOUT が 0V、液晶オンで液晶左上に緑の「C5」が出ること
- **液晶ボードと XIAO C5 の USB-C を同時に挿さないでください。** 2 つの充電回路が同じ
  電池を同時に充電します。充電は液晶ボードの USB-C だけで行います
- 使用時間の目安（未実測）: 両方で 200〜300mA 程度と見込まれ、1000mAh の電池で 2〜4 時間

**電池残量の表示**: 液晶の右上と Web 画面の上部に、液晶ボードの電池残量を % で表示します
（50% 以上は緑、20〜50% は黄、それ未満は赤。`BATTERY_LOW_PERCENT`（10%）未満は赤く点滅）。
電池の電圧から計算した目安で、USB で充電中は高めに、電池なしで USB 給電中は 100% 前後に
なります。電圧がずれるときは、シリアルモニター（115200bps）に約 10 秒ごとに出る
`battery raw=... mv=...` の mv とテスターで測った電池の電圧を比べ、`src/config.h` の
`BATTERY_MV_PER_COUNT` に「テスターの値 ÷ 表示の値」を掛けて調整してください。

MT9700 の仕様は Aerosemi のデータシートによります（WeAct モジュール自体の資料は未確認）。

### 書き込み（PlatformIO）

液晶版は、リポジトリの中の **`c5_touch_lcd` フォルダ**が別のプロジェクトになっています
（ソースは共通の `src` を使います）。

1. VS Code の「ファイル」→「フォルダーを開く」で **`c5_touch_lcd` フォルダ**を開く
2. 液晶ボードを USB 接続して「Upload」

初回は ESP32-C5 用のプラットフォーム（pioarduino 版 55.03.30-2, Arduino-ESP32 3.3.0）を
自動でダウンロードするため時間がかかります。S3 版は従来どおりリポジトリのフォルダを開いて
ビルドします。

プロジェクトを分けているのは、S3 版と液晶版のプラットフォームが同じ名前の部品
（`toolchain-riscv32-esp`、`tool-esptoolpy`）を別のバージョンで使うためです。同じ
プロジェクトにすると、一方をビルドするたびにもう一方の部品が入れ替わり、
`'riscv32-esp-elf-g++' は、内部コマンドまたは外部コマンド…として認識されていません`
のようなエラーになります。液晶版の部品は `ユーザーフォルダ\.platformio\c5\` に別に保存されます。

pioarduino の新しい版（55.03.32 以降）は通常の PlatformIO IDE ではインストールできず、
`MissingPackageManifestError: Could not find one of 'package.json' manifest files` で
止まります。そのため通常の PlatformIO IDE で使える 55.03.30-2 を指定しています。

### 画面

メイン画面（起動直後から表示）:

- 上段: C5 の接続状態（緑 `C5` / 赤 `C5未接続`）、範囲、ステップ数、1 スイープの時間
- スペクトラム: 黄（または「平均」ON で青）が現在の線、赤がピークホールド、灰色が
  ノイズ基準。表示中のバンドのチャネル位置を点線とラベルで表示。
  飽和の目安になると右上に「ゲイン下げて」を表示
- マーカー表: M1〜M4 のレベル（dBm）、近いチャネル、周波数。起動時はどのマーカーも
  選択されていません。行をタップすると
  そのマーカー（◀）を選択。選択中の行をもう一度タップすると選択だけを外します（マーカーは
  チャネル・周波数を保ったまま計測を続け、グラフをタップしても動きません）
- グラフをタップ／なぞると選択中のマーカーが移動（表示中のチャネルの近くでは
  チャネルに吸着）。指を離すと保存され、Web 画面にも反映されます
- `Hold`: ピークホールドの ON/OFF（ON のときボタンが青）
- `Ave`: 平均の線の ON/OFF（ON のときボタンが青）
- `Reset`: ピークホールドの線を消して記録し直す
- 歯車のボタン: 設定画面へ

設定画面:

- マーカー: 「M1をピークへ」などのボタンで、選択中のマーカーを一番強い点へ移動（未選択のときは「未選択」）
- 上限（dBm）・範囲（dB）を 5 ずつ変更
- 表示するバンド（A / B / E / F / R）
- ノイズ基準: 「保存」で今の平均線を基準として保存、「消去」で削除
- 画面の向き: 「縦」「横」でメイン画面の向きを切り替え（保存され、電源を切っても残ります）。
  横向きは縦の画面を右に 90 度回した向き（320×240）で、グラフをほぼ横いっぱいに表示し、
  下にマーカーを 1 行（4 つ。色の帯・dBm・周波数（MHz 単位、暗めの色）。チャネル表示なし）で
  並べます。マーカーをタップするとそのマーカーを選択、もう一度で解除。
  ボタン（Hold / Ave / Reset / 歯車）は普段は隠れていて、右端の「◀」のタブ（またはマーカー
  未選択のときのグラフ）をタップすると右からスライドして出てきます。5 秒間ボタンに触れないと
  自動で隠れます（ボタンを押すたびに 5 秒延長）。
  設定画面と詳細設定画面は縦のまま表示します。左に 90 度回した向きにしたい場合は
  `src/config.h` の `LCD_LANDSCAPE_FLIP` を 1 にしてください
- 「詳細」ボタン → 詳細設定画面:
  - 明るさ: 10〜100%（10% ずつ）
  - 省電力: 操作しない時間が設定時間（しない／10 秒〜10 分。10 秒または 1 分ずつ）たつと
    明るさ 10% に暗くなり、同じ時間がさらにたつと消灯（計測と Web 画面は続きます）。
    画面をタップすると明るさが戻ります（そのタップではボタンやマーカーは動きません）
  - どちらも保存され、電源を切っても残ります（液晶でのみ設定）

設定は Web 画面と共通で、どちらで変えても両方に反映・保存されます。範囲・ステップ幅・
ゲインなどの受信設定は Web 画面で行ってください。ピークホールドと平均の線は、液晶と
各スマホでそれぞれ別に計算しています。

タップした位置がずれる（左右・上下が逆になる）場合は、`src/config.h` の
`TOUCH_MIRROR_X` / `TOUCH_MIRROR_Y` / `TOUCH_SWAP_XY` を 1 にしてください。
液晶の明るさと省電力は、設定画面の「詳細」で変えられます（上の「画面」を参照）。

## 6. 1.47 インチ液晶版（ESP32-C5-LCD-1.47。KLAYERS / Waveshare）

ESP32-C5 と 1.47 インチ液晶（172×320）が一体になった小型ボードで使う版です。タッチパネルが
ないので、画面は表示専用（常に横向き 320×172）、操作は BOOT ボタンと Web 画面で行います。
電池の回路はないため、USB または 5V ピンから給電します。

### 配線（ボード端のピンヘッダー）

| XIAO ESP32-C5 | 1.47 インチボード |
| --- | --- |
| D6 (GPIO11, TX) | 「1」(GPIO1, RX) |
| D7 (GPIO12, RX) | 「0」(GPIO0, TX) |
| GND | 「GND」 |
| 5V | 「5V」（ボードを USB 給電するとき） |

GPIO0/1 は起動時に読まれるピン（ストラッピングピン）ではないので、XIAO をつないだままでも
起動やリセットに影響しません。ピンは `src/config.h` の `FPV_LCD147` 側で変更できます。

### 書き込み（PlatformIO）

VS Code で **`c5_lcd147` フォルダ**を開いてビルド・書き込みします（ソースは共通の `src`。
部品は液晶版と同じ `ユーザーフォルダ\.platformio\c5\` を使います）。書き込み先の COM ポートが
見つからないときは、液晶版と同じく `upload_port = COMx` を追加してください。

### 画面と操作

- 上段: C5 の接続状態、範囲、ステップ数、1 スイープの時間
- 中央: スペクトラム（横いっぱい。FPV チャネルの線とラベル、マーカー）
- 下段: マーカー 4 つを 1 行（色の帯・dBm・周波数（MHz 単位）。チャネル表示なし）
- **BOOT ボタン**: 短く押すとピークホールドの線をリセット、1 秒以上押すとピークホールドの
  ON/OFF。省電力で暗くなっているときは、最初の 1 回は明るさを戻すだけです
- マーカーの設定、表示設定、受信設定は Web 画面で行います
- Web 画面の「液晶」欄（液晶のある版だけ表示）: 明るさ（10〜100%）、省電力（操作しない
  秒数。0 = しない。時間がたつと 10% に暗くなり、同じ時間でさらに消灯）、上下反転

Web 画面の「液晶」欄は 2.8 インチ液晶版でも表示され、同じ設定を変えられます（2.8 インチの
上下反転は横向きのときに効きます）。

## 注意点

- dBm は補正値で合わせた目安です。校正された測定器の値ではありません。
- ゲイン自動（AGC）ではステップごとに感度が変わり、つなぎ目で段差が出ることが
  あります。dBm で比べるときはゲインを固定してください。
- **入力が強すぎると受信機が飽和し、実在しない位置に電波が表示されます。** 近くの VTX を
  測るときはゲインを下げるか距離をとってください。画面上部のバーに「ゲイン下げて」
  と出たら飽和の目安です（1 ビンあたり約 -30dBFS 以上）。
- 本家の実測で C5 の受信が確認されているのは 5180〜5800MHz です。**5895MHz を
  超える周波数（E6〜E8、R8 など）は実機で受信できるか確認してください。**
- 既定の 5650〜5850MHz には入らないチャネルがあります（A1 5865、B8 5866、
  E4 5645、E5〜E8、F7 5860、F8 5880、R7 5880、R8 5917）。プリセット「5640-5950」で全チャネルを
  表示できます（ステップが増えるぶん更新は遅くなります）。
- スナップショット方式のため、連続受信ではありません（各ステップで約 25ms ずつ受信）。

## ファイル構成

- `SETTINGS.md`: ステップ幅・滞在時間・検波・ゲイン・補正値の解説と使い分け

- `platformio.ini`: PlatformIO 設定（S3 版）
- `c5_touch_lcd/platformio.ini`: 液晶版の PlatformIO 設定（このフォルダを開いてビルド）
- `c5_lcd147/platformio.ini`: 1.47 インチ液晶版の PlatformIO 設定（このフォルダを開いてビルド）
- `src/lcd147_board.cpp`: 1.47 インチ液晶ボードの制御（ST7789、バックライト、BOOT ボタン）
- `src/config.h`: Wi-Fi 名・パスワード、UART ピン、初回起動時のスパン
- `src/sdr_link.*`: ESP-SDR の UART プロトコル（`SYNC`, `FREQ`, `SPEC`）クライアント
- `src/main.cpp`: スイープ処理、設定とノイズの保存（NVS）、キャプティブポータル（DNS 53）、
  WebSocket (81)
- `src/portal_http.*`: 画面を配信する小さな HTTP サーバー (80)。複数の接続を同時に扱う
- `src/index_html.h`: スマホ用の画面（HTML/JavaScript）
- `src/shared.h`: スイープ処理と液晶画面で共有する設定・状態
- `src/lcd_board.*`: 液晶版のボード制御（ST7789 液晶、CST3530 タッチ、I/O エキスパンダー）
- `src/lcd_ui.*`: 液晶版の画面（メイン画面・設定画面、タッチ操作）
- `src/lcd_font.h`: 液晶用フォント（`tools/gen_font.py` で生成。画面の日本語を
  変えたら再生成する）
